一签心愿 · 隐私政策

更新日期：2026年10月20日
生效日期：2026年10月20日

欢迎使用「一签心愿」（以下简称"本应用"）。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全。本隐私政策旨在向您说明本应用如何收集、使用、存储和保护您的信息。

一、我们收集的信息

1. 当前版本（未接入广告）：

本应用为纯本地求签工具，签文与卦象均由设备本地算法生成，不收集任何个人身份信息（包括但不限于姓名、手机号、位置、通讯录、相册）。

您在本应用内产生的收藏记录仅保存在您的设备本地（应用数据存储区），我们无法访问。

2. 未来接入广告 SDK 后：为提供广告服务，合作广告平台（如 uni-AD 聚合的穿山甲、优量汇等）可能收集以下信息用于广告投放与效果统计：设备标识信息（如 OAID、Android ID、设备型号、系统版本）、网络状态与运营商信息、粗略位置（用于本地化广告）。具体以接入时更新的本政策为准。

二、我们如何使用信息

我们仅将收集的信息用于：保障应用基础功能正常运行（如网络连接检测）、改进产品体验、以及（接入广告后）提供与展示广告内容。我们不会将您的信息出售、出租或用于本政策未说明的用途。

三、第三方 SDK

当前版本未集成任何第三方 SDK。未来若接入广告、统计等服务，将在本页面及时更新第三方 SDK 清单及其隐私说明，并在应用内隐私提示框中同步声明。

四、信息存储与安全

本地数据（如收藏记录）仅存储于您的设备。我们采取合理的技术与管理措施保护信息安全，未经您的同意，我们不会向任何第三方提供您的个人信息。

五、未成年人保护

本应用内容适合一般用户使用。若您为未成年人，请在监护人指导下使用本应用。

六、政策变更

我们可能适时修订本政策。变更后的政策将在此页面公布，并在应用内进行提示，请您定期查看。继续使用本应用即视为您同意修订后的政策。

七、联系我们

如您对本隐私政策有任何疑问，可通过应用内反馈渠道或开发者联系方式与我们联系。
